# Assistant design

The Air-Gapped assistant has been implemented using  a Hybrid Rag architecture to allow the assistant to self improve the question based on the retrieval documents and to be able to have some determinism. Design in the following diagram:

![alt text](<Assistan diagram.png>)

The tech stack used for the project is:
-	Chroma – Vector storage
-	Ollama – Local model provider
-	Portkey – Remote model provider
-	Langchain and LangGraph – Agent platform

# Effort statement

For the project the main effort was in building a reusable pipeline for multiple environments such as Local and Gateway (PortKey) given that the responses from different platforms such as Ollama and OpenAI had different implementation details.
During the development of the project I went for 3 types of architectures:
-	2-Tier RAG: Was first and simplest implementation which delivered consistent responses but lacked quality in the responses by responding only from one retrieval step
-	Deep-agent RAG: Secondly to be able to get more flexibility went for a deep-agent implementation but the pipeline started to respond more on the knowledge from the model instead of the retrieved chunks.
-	Hybrid RAG: Finally went for LangGraph implementation to be able to have more control on tools used to increase reasoning. This allowed the assistant to improve the quality of the responses mostly due to the grade document step and improve the query based on the knowledge got by the assistant previously
Also, implementing multiple chunking strategies and running experiments for Environments X Chunking strategy increase the overall time of testing and tunning the pipeline given that the more variations I made for the whole experiment setup made investigate more on why the pipeline behaved differently based on chunking and environment.
Finally collecting, analyzing and building a summarized report for the overall experiments required more investigation to understand and explain the reason behind the results, which was more of a constant iterative process of learning and improving the pipeline.

# Chunking Experiment Results

Evaluation Framework & Criteria
The strategies were evaluated across the following standard RAG performance metrics:
1.	Context Precision: The proportion of retrieved chunks that are relevant to the query.
2.	Context Recall: The extent to which all relevant information needed to answer the query was retrieved.
3.	Faithfulness / Hallucination Rate: Accuracy of generated answers relative strictly to the retrieved chunks.
4.	Processing Latency: Time required to parse, chunk, and index documents.
