
# Data Warehouse challenge

The challenge is to build a Data Warehouse using SQL by implementing all the ETL steps with SQL,
it consist of implementing all design, documentation, code and data validations.

Hints:
1. Define a naming convention for the whole project (schemas, tables, sql files, etc...)
2. For the ETL design use the medallion architecture: [reference](https://www.databricks.com/glossary/medallion-architecture)  
3. For the data modeling use the Star schema: [reference](https://www.databricks.com/glossary/star-schema)
4. Define data quality validations scripts

Extra challenges:
- Investigate Kimball methodology for DWH and implement
- Investigate Snowflake schema for data modeling
- Investigate Data vault architecture for DWH and implement
